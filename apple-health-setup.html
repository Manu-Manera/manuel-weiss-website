Apple Health → Life OS

Ein iPhone-Kurzbefehl schickt täglich Schritte, Schlaf, Training und Puls an dein Profil. Einmal einrichten, läuft automatisch – keine zusätzliche App nötig.

1 Kurzbefehl anlegen

Öffne auf dem iPhone die App Kurzbefehle → + → Name: Health an Life OS.

2 Health-Daten sammeln

Füge für jede Kennzahl die Aktion „Gesundheitsmuster suchen“ (Find Health Samples) hinzu:

AktionTypEinstellung
SchritteSchritteHeute · Gruppieren: Summe
SchlafSchlafanalyseLetzte 24 h · „Im Bett“/„Schlafend“ · Summe (in Stunden)
TrainingsminutenTrainingsminutenHeute · Summe
Aktive EnergieAktive EnergieHeute · Summe (kcal)
RuhepulsRuheherzfrequenzHeute · Durchschnitt

Speichere jedes Ergebnis mit „Variable festlegen“ (z. B. schritte, schlaf, training, energie, puls).

Füge ausserdem „Aktuelles Datum“ hinzu → Format Benutzerdefiniert: yyyy-MM-dd → Variable datum.

3 Anmelden (Token holen)

Aktion „Inhalt von URL abrufen“:

  • URL: https://cognito-idp.eu-central-1.amazonaws.com/
  • Methode: POST
  • Header:
    • Content-Type = application/x-amz-json-1.1
    • X-Amz-Target = AWSCognitoIdentityProviderService.InitiateAuth
  • Body (Datei/JSON als Text):
{
  "AuthFlow": "USER_PASSWORD_AUTH",
  "ClientId": "7kc5tt6a23fgh53d60vkefm812",
  "AuthParameters": {
    "USERNAME": "DEINE-EMAIL",
    "PASSWORD": "DEIN-PASSWORT"
  }
}

Danach: Aktion „Wert für Schlüssel abrufen“ (Get Dictionary Value) → Schlüssel AuthenticationResult.IdToken → Variable token.

E-Mail/Passwort sind dein normaler Login von manuel-weiss.ch. Sie bleiben lokal im Kurzbefehl auf deinem iPhone gespeichert.

4 Daten senden

Noch eine Aktion „Inhalt von URL abrufen“:

  • URL: https://6i6ysj9c8c.execute-api.eu-central-1.amazonaws.com/v1/user-data/workflows/apple-health/steps/datum (Variable ans Ende hängen)
  • Methode: POST
  • Header: Authorization = Bearer + Variable token (Leerzeichen nach „Bearer“!)
  • Body als JSON – Werte sind die Variablen aus Schritt 2:
{
  "steps": schritte,
  "sleepHours": schlaf,
  "exerciseMinutes": training,
  "activeEnergyKcal": energie,
  "restingHeartRate": puls
}
Teste den Kurzbefehl einmal manuell (▶︎). Antwort sollte {"success":true,…} sein – danach erscheinen die Werte im Life OS unter Fortschritt → Apple Health.

5 Automatisieren

Kurzbefehle-App → Tab Automation → + → Tageszeit → z. B. 21:30 täglich → „Sofort ausführen“ (ohne Nachfragen) → Kurzbefehl Health an Life OS wählen. Fertig.

Optional zweite Automation morgens 09:00 – dann ist auch der Schlaf der letzten Nacht aktuell.

6 Was passiert mit den Daten?

  • Speicherung pro Tag in deiner DynamoDB (Workflow apple-health), geschützt durch deinen Cognito-Login.
  • Life OS zeigt den letzten Tag + 7-Tage-Durchschnitt in der Division Körper / Energie.
  • Erfolge wie „10k-Tag“ schalten sich automatisch frei.
